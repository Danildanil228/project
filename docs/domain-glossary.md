# Словарь предметной области RF4

Документ определяет внутренний смысл терминов. Пользовательские подписи могут переводиться, машинные коды остаются стабильными.

| Термин | Внутреннее имя | Определение |
|---|---|---|
| Водоем | `waterbody` | Игровая локация, на которой доступна рыбалка |
| Версия карты | `waterbody_map_version` | Изображение и координатное преобразование карты для определенного периода игры |
| Рыба | `fish` | Вид рыбы или другого добываемого водного организма |
| Точка | `spot` | Нормализованная пара игровых координат на водоеме |
| Наблюдение точки | `spot_observation` | Свидетельство, что точка работала в конкретное время и при конкретных условиях |
| Рыболовная сессия | `fishing_session` | Ограниченный по времени выход одного пользователя на один водоем |
| Улов | `catch_event` | Событие поимки одной рыбы с известными или частично известными параметрами |
| Наживка | `bait` | Обобщенная сущность того, на что была поймана рыба |
| Натуральная наживка | `natural` | Червь, насекомое, живец и аналогичная естественная наживка |
| Подготовленная наживка | `prepared` | Тесто, каша, сыр и другая приготовленная наживка |
| Бойл | `boilie` | Бойл, pop-up или soluble бойл с размером и ароматом |
| Пеллетс | `pellet` | Пеллетс с размером и ароматом |
| Искусственная приманка | `artificial_lure` | Воблер, блесна, мягкая или морская искусственная приманка |
| Морская наживка | `marine` | Натуральная или подготовленная наживка для морской ловли |
| Компонент прикормки | `groundbait_component` | Ингредиент смеси, ПВА или прикормки |
| Способ ловли | `fishing_method` | Поплавочная, донная, спиннинговая или морская ловля |
| Оснастка | `rig` | Конкретная игровая оснастка внутри способа ловли |
| Клипса | `clip_distance_m` | Выставленная дальность заброса в метрах |
| Глубина | `depth_m` | Глубина подачи или точки в метрах |
| Вес | `weight_g` | Вес улова в целых граммах |
| Игровое время | `game_time_minute` | Минута игровых суток от 0 до 1439 |
| Реальное время | `caught_at` | Момент события в UTC, если он известен |
| Регион | `region_code` | Регион официальной статистики, например `RU`, `DE`, `US` |
| Источник | `source` | Происхождение данных: пользователь, официальный ресурс или разрешенный импорт |
| Уверенность | `confidence` | Техническая уверенность распознавания поля, а не доверие к автору |
| Доверие | `trust_score` | Объяснимый показатель качества набора наблюдений |
| Трофейный статус | `trophy_class` | Обычный, трофейный или редкий трофей по правилам периода и региона |
| Патч | `game_patch` | Версия или дата изменения игровых правил и справочников |

## Правила единиц

- вес хранится в граммах целым числом;
- денежные значения хранятся как `NUMERIC(12,2)`;
- длительность хранится в секундах;
- глубина хранится в метрах с точностью до сантиметра;
- даты хранятся в UTC (`TIMESTAMPTZ`);
- игровые координаты хранятся отдельно по X и Y;
- исходная строка импорта сохраняется отдельно от нормализованных значений.

## Подтвержденные официальным руководством области

Официальное руководство отдельно описывает поплавочную, спиннинговую, донную и морскую ловлю; удилища, катушки, крючки, лески, оснастки, ремонт, состояние персонажа, время, погоду, наживки, приманки и прикормку. Это подтверждает необходимость разделять эти сущности в модели.
