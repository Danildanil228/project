## Отчёты

Каталог `_reports` содержит:

- `catalogue.csv` — соответствие исходного файла и восстановленного пути;
- `conflicts.csv` — неоднозначные имена;
- `missing-from-source.csv` — записи манифестов без файла в этом экспорте;
- `unmapped-source.csv` — файлы без точного пути в манифестах;
- `review-classification.csv` — предварительная классификация служебных деталей;
- `summary.json` — сводные показатели запуска.

Скрипт идемпотентен: повторный запуск не перезаписывает файлы и отражает конфликты в отчёте.

## Тестовые данные

`back/seeds/001_baits.sql` содержит небольшой набор приманок, чьи типы однозначно следуют из путей манифеста. Внутренние коды бойлов, пеллетсов и искусственных приманок не преобразованы в пользовательские названия без дополнительного справочника.

После применения миграций локальную базу можно наполнить командой:

```powershell
cd back
npm run seed
```

Команда отказывается работать при `NODE_ENV=production` и с удалённым `DB_HOST`.
